# Ebbinghaus 复习小助手

一个**单文件、零依赖、纯本地**的间隔重复（Spaced Repetition）复习工具。双击 `index.html` 即可使用，无需安装任何东西，数据完全保存在你自己的浏览器里。

## 为什么是它

- **单文件交付**：HTML + CSS + JS 全部内联在一个文件里，拷走即用，离线可用
- **隐私友好**：数据存在浏览器 IndexedDB（含 localStorage 镜像备份），不上传、不联网、无追踪
- **开箱即用**：无需注册、无需服务器、无需构建工具

## 功能特性

- **艾宾浩斯复习曲线**：新知识点按 +1 / +2 / +4 / +7 / +15 / +30 天自动排程
- **双阶段引擎**：基础轮（6 次）完成后自动进入"滚动维持轮"，可自定义维持周期、冲刺期（考前自动加密复习）与截止日期
- **真实日期锚定**：按你**实际完成复习的日期**重新推算后续间隔，而不是按原计划日死板推进
- **逾期智能处理**：
  - 同一知识点的多次逾期自动合并成一张卡片，不再一天重复刷多遍
  - 部分补偿调度：一次复习抵扣有限轮次，剩余欠账进入"巩固补练"队列，符合间隔效应原理
- **每日上限**：默认每日 40 条封顶，超量自动顺延，冲刺期自动放宽
- **记忆统计**：基于真实提取次数估算每个知识点的保持率（R 值），并标注被"抵扣"的次数
- **知识库管理**：关键词搜索 + 多级筛选（按命名约定自动识别学科 / 章节 / 形式）
- **数据安全**：一键导出 / 导入 JSON 备份；每次保存自动写入 localStorage 镜像，可一键恢复
- **体验细节**：首页问候语与名人名言轮播、卡片入场动效（尊重系统减弱动效设置，也可手动开关）、响应式左右分栏布局、暗色适配

## 快速开始

1. 下载 `index.html`
2. 双击用浏览器打开（推荐 Chrome / Edge）
3. 在「添加知识点」录入你今天要学的内容，之后每天打开它按提示复习即可

> ⚠️ **注意**：浏览器按文件路径隔离本地数据（`file://` origin）。**请不要重命名或移动 HTML 文件**，否则原有数据会"找不到"。如需迁移，请先使用页面内的「导出」功能备份，再在新位置「导入」。

## 数据与备份

| 操作 | 位置 |
|------|------|
| 导出备份 | 设置页 → 导出 JSON |
| 导入恢复 | 设置页 → 导入 JSON（按 ID 合并，进度取并集，不会覆盖） |
| 自动镜像 | 每次保存自动写入 localStorage，异常时可在设置页一键恢复 |

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无任何框架与构建步骤
- 存储：IndexedDB（主）+ localStorage（镜像备份）
- 复习间隔模型：固定阶梯 `[1, 2, 4, 7, 15, 30]` 天 + 可配置维持周期
- 保持率估算：`S = 3 × 1.6^真实提取次数`，`R = 0.5^(距今天数 / S)`
